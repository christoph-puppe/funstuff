Cross-vendor self-identification

Read this before drawing conclusions. A model naming another vendor is weak evidence of distillation on its own. Post-2023 web corpora are saturated with transcripts of other assistants, so "I am ChatGPT" is a high-probability completion for any base model trained on scraped text — no teacher model required. Identity is also normally installed at deployment via system prompt, not trained into weights, so an unprompted model is largely guessing. The inference fails in reverse too: identity fine-tuning is cheap, so absence of this signal rules nothing out. Treat the tiers below as where to look next, never as a finding. Corroboration means training-data disclosures, licence terms, tokeniser and logit-level analysis — not a chat transcript.
