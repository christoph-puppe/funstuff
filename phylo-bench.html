◈GENOMEnot built

Each gene is a passage truncated at a random character between 20 and 100, seeded per genome id, so the cut points are reproducible. The genome is hashed on build; distances computed against different genome hashes are not comparable and the tool refuses to merge them. Paste recent text you have reason to believe is not in any training set. Two genomes minimum: clustering shifts between reasoning and code text, and that divergence is itself a result.

◇COHORT

One entry per line: model_id | iface | tok:family. iface is chat (wrapper applied, /chat/completions) or base (raw prefix, /completions). tok declares the tokenizer family; entries sharing a family become eligible for exact-token comparison, everything else is compared on the first K characters. Append | rep:2 to probe the same endpoint a second time independently, which is how the self-distance anchor gets its noise floor. Lines starting with # are ignored.

⬡CALIBRATION ANCHORS

Self-distance comes from any model carrying a rep:2 entry and is the noise floor: endpoint nondeterminism plus sampling variance, the number below which nothing means anything. The run is marked INVALID unless self < related < unrelated holds. An instrument that fails its own ordering test does not get to produce a tree.

⌕FINDING

⋯METHOD

Metric. Each gene is a truncated text prefix. For every model and gene, the tool collects N one-token continuations and counts alleles: the exact returned token when two models share a declared tokenizer, otherwise the first K characters. Allele frequency vectors give Nei's standard genetic identity, I = Σ p·q / sqrt(Σ p² · Σ q²) pooled over genes, and distance D = −ln I. Sampling is the estimator. Logprobs, where available, are an optional low-variance fast path selected for the whole run, never mixed into one matrix, and a model that will not return them is excluded rather than silently resampled.

Two modes, never mixed. Exact-token comparison and first-K-character comparison have different resolution and different scale. Every pairwise distance carries the mode that produced it, matrices are built per mode, and the tree refuses to draw from mixed-mode input. The character mode is dominated by early-token behaviour, which is the known weakness of the approach.

Sampling parameters. Temperature 1 or above, top_p 1, top_k not sent. Temperature 0 collapses every gene to a single allele at frequency 1 and destroys the signal, so the tool refuses to run there. Nucleus and top-k truncation distort the tail the metric depends on. Temperature, top_p, top_k, seed, requested model, returned model string, provider, endpoint and timestamp are recorded on every draw.

What a small distance means. Functional similarity, which is consistent with shared weights, a shared corpus, a shared teacher, similar post-training, or convergence on the same objective. It cannot separate those. The tool emits a similarity finding plus an explicit alternative-hypothesis list, a deterministic guard rejects causal phrasing, and the checker pass is instructed to fail any output that reads as an accusation. This is the same documented-versus-speculation split you would apply in a write-up, enforced in the pipeline instead.

Prior art. The metric follows PhyloLM (Yax, Oudeyer, Palminteri, ICLR 2025), including its two-mode design. LLM DNA (Wu et al., arXiv 2509.24496) benchmarks against it and reports better relation detection from a sentence-embedding pipeline; their ablations also found that random-word genomes performed slightly better than curated benchmark text, that dropping chat templates improved cross-family comparison, and that some APIs refuse to continue random strings. Read both before trusting either.
