▣AGREEMENT ON CONFABULATED VALUES

Cell = share of co-confabulated items where both models invented a matching value. The cohort itself is the null: pairs are flagged when their agreement sits more than the threshold above the cohort mean in standard deviations, computed only over pairs with at least the minimum co-answered count. Excess agreement is a lineage signal — shared training ancestry, shared SFT corpora, or distillation. The matrix cannot tell those three apart.

◬METHOD & CAVEATS

Mechanism. A Nihilartikel is the cartographer's trap street: a deliberately fictitious entry that only a copier reproduces. This tool generates fictitious technical entities, asks every model a loaded question that presupposes each entity exists, and compares the inventions. Independent models agreeing on truths is expected. Models agreeing on the same fabrications beyond the cohort baseline share ancestry.

Pipeline. Stage 1 probes every model at temperature 0, one trial per item, the mode of the distribution being the fingerprint. Stage 2 has a cheap blind extractor classify each answer (answered / denied / refused / unclear) and pull the atomic value; it never sees which model produced the text. Stage 3 is deterministic JavaScript: normalisation, pairwise agreement, cohort z-scores. Rulebook version is stamped separately from the tool version, and a saved export can be re-scored without any API call.

Unscoreable is a first-class verdict. Empty completions (including reasoning-only responses), API errors, and extraction failures are excluded from every rate and counted visibly. They are never filed as model behaviour.

What a flagged pair is not. It is not proof of distillation. Shared open SFT datasets, common synthetic pipelines, and a genuine base-model relationship produce the same signal. It is lineage evidence at the ceiling of what outsider API access can establish; canaries and watermarks planted by the teacher before the dispute remain the only court-grade tier.

Known limits of v0.1. Items are probabilistically fictitious, not verified against registries; a rare collision with a real entity turns that item into a knowledge probe, which is why the item list is editable and exported. Some item categories have lower answer entropy than others; per-item distinct-value counts are in the export so you can weigh them. One trial per item means no within-model stability estimate. Agreement uses normalised string match with containment, which is crude for multi-word values. Statistics treat items as independent, which templates only approximate. If a model provider rejects temperature 0, the call fails loudly rather than silently resampling.

CORS. OpenRouter permits browser calls from file://. If your setup blocks it, serve the file with python -m http.server and open it via localhost.
